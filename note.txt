-------------------Book API---------------------------
POST ----> "http://localhost:5000/book" ----> Add Data
GET  ----> "http://localhost:5000/book" ----> Fetch Data
PUT  ----> "http://localhost:5000/book/:id"-> Update Data By id
DELETE---> "http://localhost:5000/book/:id"-> Delete Data By id
